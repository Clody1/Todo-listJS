#  To-Do List

Une petite application web de gestion de tâches réalisée avec **HTML, CSS et JavaScript**.

Ce projet a été créé pour pratiquer la manipulation du **DOM (Document Object Model)** avec JavaScript et comprendre comment rendre une page web interactive.

##  Objectif du projet

L'objectif est de créer une application permettant à l'utilisateur de gérer facilement ses tâches :

* Ajouter une tâche
* Marquer une tâche comme terminée
* Supprimer une tâche
* Filtrer les tâches
* Afficher le nombre de tâches restantes

##  Fonctionnalités

###  Ajouter une tâche(Termire)

L'utilisateur peut saisir une tâche dans le formulaire et l'ajouter à la liste.

###  Marquer comme terminée(pas encore)

Une tâche peut être marquée comme terminée. Son texte apparaît alors barré.

### Supprimer une tâche(pas encore)

L'utilisateur peut supprimer une tâche de la liste.

###  Filtrer les tâches(pas encore)

Trois filtres sont disponibles :

* **Toutes** : affiche toutes les tâches
* **Actives** : affiche uniquement les tâches non terminées
* **Complétées** : affiche uniquement les tâches terminées

###  Compteur( pas encore )

L'application affiche le nombre de tâches qui restent à effectuer.

##  Technologies utilisées

* **HTML5** : structure de la page
* **CSS3** : mise en forme et design
* **JavaScript** : logique et manipulation du DOM
